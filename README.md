# Tic Tac Toe Game

This is a simple Tic Tac Toe game that I built using HTML, CSS, and JavaScript.
The main goal of this project was to practice basic frontend development concepts like layout design, DOM manipulation, and game logic

## What this project does

* Two players can play (X and O)
* The game automatically checks who wins
* If all boxes are filled, it shows a draw
* A popup screen appears to show the result
* There is a button to start a new game
* The design works well on mobile and desktop

##  Project files

* **index.html** – contains the structure of the game 
* **style.css** – handles the design and layout 
* **script.js** – controls the game logic and interactions 

##  How to run

1. Download or copy the files
2. Keep all three files in the same folder
3. Open `index.html` in your browser

That’s it—you can start playing immediately.
